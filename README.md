# 💊 Meditrack

Meditrack is an Android app that helps users manage their medications, set reminders, and stay on track with their medication.

---

## ✨ Features

- Add, edit, and delete medications  
- Set reminders for doses  
- Search medications using an API 
- User login and profile management  
- Clean and modern UI (Jetpack Compose)

---

## 🛠️ Tech Stack

- Kotlin  
- Jetpack Compose  
- MVVM Architecture  
- Navigation Component  
- Retrofit (API calls)

---

## 📱 Screens

- Login / Register  
- Home  
- Medication List  
- Add / Edit Medication  
- Medication Lookup  
- Settings / Profile  

---

## 🚀 How to Run

1. Download the MediTrack-Final.apk file onto your phone (Android only, as i have not done cross platforming on
   this project to be compatable with Apple)

   or

1. you can download this folder and open it up in android studio and run it from there on an emulator
